# 🎓 Student Performance Analyzer

A beginner-friendly Python and NumPy project that analyzes student marks, calculates academic performance, and identifies the class topper.

This project was built to practice Python fundamentals and understand how NumPy simplifies numerical calculations using arrays.

## 🚀 Features

- Calculate total marks for each student.
- Calculate individual percentages.
- Identify PASS/FAIL results based on subject marks.
- Calculate subject-wise class averages.
- Find the highest and lowest individual marks.
- Calculate the overall class average.
- Identify the student with the highest total marks.
- Display a class performance summary.

## 🛠️ Tech Stack

- **Python 3** — Programming logic, loops, and conditional statements.
- **NumPy** — Array operations and numerical calculations.
